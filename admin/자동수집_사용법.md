# 카카오톡 → Supabase 자동 수집기

## 버전 선택

### 1. 완전 자동 버전 (추천)
- **파일**: `supabase_auto_start.bat`
- **특징**: 실행만 하면 자동으로 수집
- **방식**: pyautokakao.read() 사용

### 2. 클립보드 버전 (안정)
- **파일**: `supabase_collector_start.bat`
- **특징**: 카톡에서 Ctrl+A → Ctrl+C 필요
- **방식**: 클립보드 감시

---

## 완전 자동 버전 사용법

### 사전 준비

1. **카카오톡 PC버전 실행** (필수)
2. **Supabase에 함수 생성** (최초 1회):

```sql
CREATE OR REPLACE FUNCTION increment_member_exp(
  p_member_id UUID,
  p_exp INTEGER
) RETURNS VOID AS $$
BEGIN
  UPDATE members
  SET accumulated_exp = accumulated_exp + p_exp, updated_at = NOW()
  WHERE id = p_member_id;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```

### 실행

`supabase_auto_start.bat` 더블클릭

### 작동 방식

1. 10초마다 자동으로 카카오톡 채팅방 읽기
2. 인증 태그(#청소, #운동 등) 감지
3. Supabase DB에 자동 저장
4. 멤버 EXP 자동 증가

### 종료

`Ctrl+C`

---

## 클립보드 버전 사용법

### 실행

`supabase_collector_start.bat` 더블클릭

### 사용법

1. 수집기 실행
2. **카카오톡 채팅방**에서 `Ctrl+A` (전체선택)
3. `Ctrl+C` (복사)
4. **자동으로 인증이 수집됩니다!**

### 단축키

| 키 | 기능 |
|----|------|
| F8 | 수동 수집 (현재 클립보드) |
| F10 | 통계 보기 |
| F12 | 멤버 새로고침 |
| Esc | 종료 |

## 문제 해결

### "Supabase 연결 실패"
- URL/Key 확인
- 인터넷 연결 확인

### "채팅방을 찾을 수 없습니다"
- 카카오톡 PC버전이 실행 중인지 확인
- 채팅방 이름이 정확한지 확인 (설정 파일에서 수정)

### "미등록" 멤버
- 웹 관리자에서 해당 멤버 추가
- 또는 member_aliases 테이블에 카카오 닉네임 등록

### 인증이 수집 안됨
- 인증 태그(#청소, #운동 등)가 있는지 확인
- 일일 제한에 걸렸는지 확인
